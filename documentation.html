Fastify‑модуль gpt/src/index.ts

Модуль инициализирует веб‑сервер Fastify, который служит единым входом для вспомогательных скриптов проекта агрегатора обменников. Каждая ручка запускает отдельный сценарий обработки данных: парсинг BestChange, получение реферальных ссылок, поиск XML‑фидов, создание карточек обменников в Strapi, генерацию текстов направлений/городов, а также заполнение статей и описаний.

Основные функции и эндпоинты

  • GET /parsebest – вызывает parseBest() для парсинга списка обменников BestChange и сохранения результата в bc-scraped.json.
  • GET /fillreal – запускает fillRealLinks(), который с помощью Puppeteer открывает страницы BestChange, снимает ограничения и вытаскивает реальные ссылки обменников в bc-real-links.json.
  • GET /findxml – инициирует findxml() для перебора доменов обменников и поиска доступных XML‑фидов, результат сохраняется в bc-xml.json.
  • GET /create – вызывает createExchangers(), который сравнивает текущие данные Strapi и создаёт недостающие карточки обменников через GraphQL‑мутации.
  • GET /load_html – запускает loadHTML() для открытия сайтов обменников в реальном Chrome и сохранения HTML снимков в директорию saved/.
  • GET /descriptions_auto – выполняет fillDescriptionsAuto(), который скрапит сайты обменников, отправляет данные в GPT и записывает описания в Strapi.
  • GET /descriptions_file – вызывает fillDescriptionsFromFile(), читающий сохранённые HTML и генерирующий описания на их основе.
  • GET /health – использует checkHealthXML() для проверки доступности реферальных ссылок и XML‑фидов (HEAD‑запросы).
  • GET /fill_dirs – запускает fillDirs() для генерации текстов направлений (EN/RU) по slug‑ам, отсутствующим в Strapi.
  • GET /fill_dirs_cities – вызывает fillCityDirs(), создающий текстовые блоки направлений с привязкой к городам (slug + город).
  • GET /fill_cities – выполняет fillCities(), формируя общие описания городов для страницы направлений.
  • GET /default_dirs – инициирует generateDefaultDirTexts() для генерации запасных текстов направлений по парам секций.
  • GET /default_mass_dirs – запускает generateDefaultMassDirTexts(), создающий массовые тексты для всех пар криптовалюта ↔ фиат.
  • GET /section=:sectionName – вызывает fillArticles(sectionName) для генерации статей (EN + RU) по заданному разделу селектора.
  • GET /change_exchanger_names – выполняет changeExchangerNames(), нормализующий отображаемые названия обменников (удаление дефисов и др.).

Сервер запускается на порту из переменной окружения PORT и требует успешной авторизации в Strapi (функция auth()) перед выполнением автоматизированных сценариев.
